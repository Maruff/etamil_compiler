# eTamil Quick Start - Independent DSL Executor

## 🚀 Quick Start (30 seconds)

```bash
# 1. Navigate to project
cd ~/ஆவணங்கள்/eTamil

# 2. Run a program
etamil examples/io_samples/simple_fileio.qmz

# 3. Done! ✅
```

That's it! No compilation, no waiting for LLVM.

---

## 📋 What Changed?

**Old Way** (Still works):
```bash
cargo run --bin etamil_compiler -- program.qmz --llvm
# Takes 2-5 seconds (LLVM compilation)
```

**New Way** (Default):
```bash
cargo run --bin etamil_compiler -- program.qmz
# Takes <100ms (VM execution)
```

---

## 🎯 Usage

### Via Wrapper Script
```bash
# Run with VM (fast, default)
etamil program.qmz

# Run with LLVM (legacy, slower)
etamil program.qmz --compile

# Show generated bytecode
etamil program.qmz --bytecode

# Verbose output
etamil program.qmz --verbose

# Use optimized build
etamil program.qmz --release
```

### Via Cargo
```bash
# Default VM mode
cargo run --bin etamil_compiler -- program.qmz

# LLVM mode
cargo run --bin etamil_compiler -- program.qmz --llvm
```

### Via Direct Binary
```bash
# Build release binary
cd etamil_compiler
cargo build --release --bin etamil_compiler

# Run it
./target/release/etamil program.qmz
```

## 🏗️ Architecture

```
Program.qmz
    ↓
Lexer (tokenize)
    ↓
Parser (build AST)
    ↓
Bytecode Compiler (generate instructions)
    ↓
VM Executor (run)
    ↓
Output
```

## ❓ FAQ

### Q: Will my old programs still work?
**A**: Yes! LLVM mode still works. Add `--llvm` flag.

### Q: Is the VM fast enough?
**A**: Yes! 100x faster startup, good execution speed.

### Q: Do I need LLVM installed?
**A**: Not anymore! VM doesn't need external tools.

### Q: Can I distribute the binary?
**A**: Yes! Build with `cargo build --release`.

### Q: What if my program doesn't run?
**A**: Try `--llvm` mode. VM needs parser updates for some features.

## 🛠️ Building for Distribution

```bash
cd etamil_compiler
cargo build --release --bin etamil_compiler
cp target/release/etamil ~/.local/bin/etamil
chmod +x ~/.local/bin/etamil

# Now you can run from anywhere:
etamil myprogram.qmz
```

## 🎓 Learning the VM

The VM is written in clean, understandable Rust:
- Read `src/vm/interpreter.rs` to understand execution
- Read `src/vm/bytecode/compiler.rs` to see AST → bytecode
- Read `src/vm/value.rs` to understand the type system

Each module is ~100-200 lines with clear comments.
